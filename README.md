# BookOasis

- Mihon 기반의 BookOasis 안드로이드 리더와 Mihon 확장 저장소

## 안드로이드 앱

- **[최신 APK 다운로드](https://github.com/hongho55/bookoasis-mihon-repo/releases/latest/download/BookOasis-v31-arm64.apk)**
- Android 8.0 이상 · ARM64
- EPUB · TXT · PDF · ZIP · CBZ 읽기
- 서버 도서 검색 · 다운로드 · 오프라인 읽기
- 별도 서버 플러그인 없이 읽기 위치 동기화
- 앱 소스: [`android/`](android/)

## Mihon 확장

- 기존 ZIP/CBZ 확장과 배포 파일 유지
- 확장 소스: [`src/`](src/)
- 확장 저장소 주소: `https://raw.githubusercontent.com/hongho55/bookoasis-mihon-repo/main/index.min.json`
